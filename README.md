# 拾光书城 · 在线图书商城（HTML5 + CSS3 + JavaScript 单页应用）

一个不依赖任何框架、不依赖构建工具、不依赖后端接口的图书商城单页应用。
所有数据都是本地模拟数据，双击 `index.html` 就能在浏览器里直接运行。

---

## 一、怎么运行

1. 找到 `index.html`，双击用浏览器（Edge / Chrome）打开；
2. 完成。不需要装 Node.js，不需要 `npm install`，不需要开本地服务器。

> 说明：页面用到的图标全部是代码里写好的内联 SVG，书封是用 CSS 渐变生成的，
> 没有任何外链图片、字体或 CDN 资源，所以断网也能正常显示。

如果需要用本地服务器打开（可选）：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 二、功能清单

### 基础功能

| 要求 | 实现位置 |
| --- | --- |
| 首页：轮播广告 | 首页顶部轮播，3 张幻灯片，自动播放（5 秒）+ 左右箭头 + 圆点，鼠标悬停时暂停 |
| 首页：图书分类导航 | 8 个分类卡片，显示分类说明与该类图书数量，点击进入对应列表 |

| 列表页：图书展示 / 价格 / 库存 | `#/books`，卡片显示售价、定价、折扣、评分、销量，封面上有“现货 / 仅剩 N 本 / 缺货”标签 |
| 列表页：按名称搜索 | 顶部搜索框（全局）+ 列表页搜索框，支持书名、作者、出版社、标签、分类名 |
| 列表页：分类筛选 | 左侧分类列表（带数量）、价格区间、仅看有货；另支持 5 种排序 |
| 详情页：图书介绍 | 内容简介、编辑推荐、图书信息表、读者评价、同类推荐 |
| 详情页：加入购物车 | 可选数量后加入购物车，库存不足会给出提示；另有“立即购买”直达结算 |
| 购物车：修改数量 / 删除 / 总价 | 数量步进器（含手工输入）、单本删除、清空购物车、商品金额 / 运费 / 应付总额 |
| 结算：模拟下单 | `#/checkout`，填写收货信息 + 选择支付方式，校验通过后生成订单号并显示订单结果 |

### 拓展功能

- **商品收藏**：卡片和详情页都能收藏，`#/favorites` 集中查看，导航栏有收藏数量角标；
- **本地存储**：购物车与收藏夹写入 `localStorage`，关掉浏览器再打开数据还在。

## 三、文件结构

```
bookstore/
├── index.html            页面骨架：头部、内容容器、页脚、脚本引入
├── css/
│   └── style.css         全部样式（变量、布局、组件、响应式）
├── js/
│   ├── data.js           模拟数据：分类、图书、轮播位
│   ├── util.js           工具函数：金额、星级、图标、逃逸、DOM 简写
│   ├── store.js          状态层：购物车 / 收藏夹 + localStorage + 发布订阅
│   ├── router.js         hash 路由：解析地址、跳转、参数合并
│   ├── components.js     可复用片段：封面、图书卡片、轮播、步进器、空状态
│   ├── views.js          页面视图：首页、列表、详情、购物车、结算、收藏
│   └── app.js            入口：渲染导航、按路由渲染页面、全局事件处理
└── README.md             本文件
```

脚本必须按上面 `js/` 的顺序引入（`index.html` 里已经排好）：
工具 → 数据 → 状态 → 路由 → 组件 → 视图 → 入口。

## 四、几个关键实现思路

**1）单页应用与路由**
所有页面共用一个 `index.html`，靠地址栏的 hash（`#/books`、`#/book/3`）切换内容：

```
#/                        首页
#/books?cat=computer      列表页（分类 / 关键词 / 排序 / 价格 / 库存参数都写在地址里）
#/book/3                  详情页
#/cart                    购物车
#/checkout                结算
#/favorites               收藏
```

`router.js` 监听 `hashchange` 事件重新解析地址并通知 `app.js` 重画页面。
这样刷新、前进后退、把链接发给别人，都能回到同一个页面状态。

**2）页面渲染**
`views.js` 里每个视图的 `render()` 返回一段 HTML 字符串，`app.js` 把它塞进
`#view` 容器即可。数据变化时重新执行 `render()`，不需要手动修改 DOM 的每一处。

**3）事件委托**
页面上的按钮统一写成 `data-action="add-cart" data-id="3"`，
`app.js` 在 `document` 上监听一次点击事件，再根据 `data-action` 分发处理。
好处是页面整块重画后不用重新绑定事件，也不会出现重复绑定。

**4）状态与本地存储**
`store.js` 用一个对象保存 `cart` 和 `favorites`，
每次修改都会写进 `localStorage` 并通知订阅者刷新界面（发布订阅模式）：

```js
localStorage['shiguang.cart.v1']      // [{"id":3,"qty":2}, ...]
localStorage['shiguang.favorite.v1']  // [3, 14, ...]
```

想清空数据：浏览器控制台执行 `localStorage.clear()` 后刷新。

**5）满 99 元免运费**
运费规则写在 `store.js` 顶部（`FREE_SHIPPING = 99`，`SHIPPING_FEE = 8`），
购物车和结算页共用同一套计算，所以两处金额永远一致。

## 五、可以继续扩展的方向

- 给列表页加分页或“上拉加载”；
- 收藏夹增加“移入购物车”；
- 结算页增加优惠券、发票信息；
- 用 `sessionStorage` 保存最近浏览的图书；
- 把 `data.js` 换成真实的 `fetch()` 请求，其余代码几乎不用改。
